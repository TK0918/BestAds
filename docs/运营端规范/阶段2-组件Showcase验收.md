# 阶段 2：运营端组件 Showcase 验收

## 1. 预览入口

```text
http://127.0.0.1:4173/index.html
```

入口文件：`prototype-kit/showcase/index.html`

## 2. 本阶段验收范围

组件 Showcase 只确认可复用的视觉和交互基线，不确认具体业务页面字段。

### 公共 Shell

- Logo、侧边菜单、菜单分组、当前菜单高亮。
- 顶部面包屑、用户区域、主题切换。
- 页面级 Tab 和业务 Tab 的层级关系。

### 基础组件

- Primary / Default / Danger / Link 按钮。
- Vben Form 查询表单、输入框、下拉框、搜索和重置。
- AntD Tag 状态颜色和状态文案。
- VXE Grid 表头、选择列、固定操作列、分页。

### 状态与反馈

- 默认、加载中、空数据、网络错误、无权限。
- 提交中、成功、失败提示。
- 二次确认弹窗和危险操作颜色。

### 运营端业务组件

- 权限树弹窗。
- 字段定制。
- 异步导出任务提示。
- 账户金额表单和充值抽屉示例。

## 3. 请用户验收

- [ ] 运营端整体密度、字号、圆角、颜色与真实系统方向一致。
- [ ] 浅色/深色模式切换后，文字、边框、背景和状态标签仍可读。
- [ ] 查询区、列表区、弹窗和分页的间距符合运营端使用习惯。
- [ ] Danger 操作统一使用危险色，普通行内操作使用主色 Link。
- [ ] Loading、Empty、Error、Authority 四类异常状态足以作为后续页面模板。
- [ ] 后续业务页面只引用 Showcase 已验收的组件模式，不单独发明同类样式。

## 4. 当前约束

- Showcase 是 HTML 评审入口，不等于真实 Vue 组件源码。
- 运营端真实实现仍以 Vben Admin、Ant Design Vue、VXE Grid 和后端接口契约为准。
- 未验收的组件不得写入全局产品规范，也不得直接复制到全部业务页面。
