运营端组件基线

只纳入前端上下文中已确认实际使用的组件，作为后续 HTML 原型的组合积木。

Vben · AntD · VXE
Page + ACard页面容器 / 查询卡 / 表格卡
layout
客户管理

列表数据

典型列表页采用 `Page auto-content-height`，上方查询 `ACard`，下方卡片占满剩余高度。

Vben Form查询表单 / 72px labelWidth
form

查询区由 `useVbenForm` 承载，表单 actions 默认由 schema 统一生成，页面通过 `handleSubmit/handleReset` 刷新 Grid。

Vben Modal + AntD Tree权限管理 / 批量功能开关

EditListFields + ExportTask字段定制 / 异步导出任务
